Wahrscheinlichkeiten · Stunde 2

Ist das Spiel unfair?

Problem

Anna und Ben spielen am Spieleabend ein Würfelspiel. Es wird reihum gewürfelt:
🟢 Anna bekommt einen Punkt bei einer geraden Zahl.
🔵 Ben bekommt einen Punkt bei einer Zahl größer als 4.

Nach einer Weile ruft Ben: „Das ist unfair! Anna gewinnt immer!“

Hat Ben recht? Was meint ihr? Stimmt ab und begründet!

Kurz die Hausaufgabe aufgreifen (1–2 Zufallsexperimente nennen lassen). Dann Problem vorlesen, Abstimmung per Handzeichen an der Tafel festhalten. Noch nicht auflösen.
Erarbeitung I · Partnerarbeit

Spielt es selbst!

  1. Einer ist Anna, einer ist Ben.
  2. Würfelt 20-mal abwechselnd.
  3. Macht bei jedem Wurf einen Strich für den, der einen Punkt bekommt. Achtung: Manchmal bekommen beide einen Punkt, manchmal keiner!

Sicherung

Ergebnis und Ereignis

Merke

  • Ein Ergebnis ist ein einzelner möglicher Ausgang eines Zufallsexperiments.
    Würfel: 1, 2, 3, 4, 5 oder 6
  • Ein Ereignis fasst ein oder mehrere Ergebnisse zusammen.
    „gerade Zahl“ = { 2, 4, 6 }
  • Ein Ereignis tritt ein, wenn eines seiner Ergebnisse fällt.
    Fällt eine 4, ist „gerade Zahl“ eingetreten. Anna bekommt einen Punkt.
  • Enthält ein Ereignis alle Ergebnisse, ist es ein sicheres Ereignis. Enthält es kein Ergebnis, ist es ein unmögliches Ereignis: { }
Merksatz ins Heft. Abgrenzung betonen: Das Ergebnis ist das, was tatsächlich fällt. Das Ereignis ist das, worauf man setzt.

Abschluss · zurück zum Problem

Ben hat recht. Wie wird das Spiel fair?

Anna: gerade Zahl = { 2, 4, 6 }

Ben: größer als 4 = { 5, 6 }

Fair wäre z. B.:

Ben: größer als 3 = { 4, 5, 6 }
