Ergebnisse und Ereignisse

Heute lernst du, wie man mehrere Ergebnisse zu einem Ereignis zusammenfasst.

Wiederholung: Nenne ein Zufallsexperiment aus deiner Hausaufgabe und alle möglichen Ergebnisse.

Hausaufgabe kurz vergleichen (2–3 Beispiele an die Tafel). Auf richtige Schreibweise mit geschweiften Klammern achten.

Sicherung

Ergebnis und Ereignis

Merke

  • Ein Ergebnis ist ein einzelner möglicher Ausgang eines Zufallsexperiments.
    Würfel: 1, 2, 3, 4, 5 oder 6
  • Ein Ereignis fasst ein oder mehrere Ergebnisse zusammen.
    „gerade Zahl“ = { 2, 4, 6 }
  • Ein Ereignis tritt ein, wenn eines seiner Ergebnisse fällt.
    Fällt eine 4, ist „gerade Zahl“ eingetreten.
  • Enthält ein Ereignis alle Ergebnisse, ist es ein sicheres Ereignis. Enthält es kein Ergebnis, ist es ein unmögliches Ereignis: { }
Merksatz ins Heft. Abgrenzung betonen: Das Ergebnis ist das, was tatsächlich fällt. Das Ereignis ist das, worauf man wettet.
Übung · Einzelarbeit

Das Glücksrad

Schreibe die Ereignisse als Menge auf.

a
Das Rad bleibt auf Rot stehen.
{ 1, 4, 7 }
b
Es kommt eine gerade Zahl.
{ 2, 4, 6, 8 }
c
Es kommt eine Zahl kleiner als 3.
{ 1, 2 }
Zum Abschluss der Folie das Rad drehen: Ist Ereignis a, b oder c eingetreten? So wird das „Eintreten“ geübt.

Das Glücksrad: weiter geht's

d
Es kommt eine Zahl größer als 8. Was für ein Ereignis ist das?
{ } – ein unmögliches Ereignis
e
Beschreibe das Ereignis { 3, 6 } in Worten.
„Das Rad bleibt auf Gelb stehen.“ oder „Die Zahl ist durch 3 teilbar.“
★
Es kommt eine blaue und gerade Zahl.
{ 2, 8 }
★
Erfinde selbst ein Ereignis mit genau 3 Ergebnissen.
z. B. „ungerade Zahl kleiner als 6“ = { 1, 3, 5 }
★-Aufgaben für schnelle Schüler. Bei e) beide Beschreibungen würdigen: Zu einer Menge kann es mehrere Beschreibungen geben.
Abschluss

Zurück zu Anna und Ben

Anna: gerade Zahl

{ 2, 4, 6 } → 3 Ergebnisse

Ben: Zahl größer als 4

{ 5, 6 } → 2 Ergebnisse

Annas Ereignis enthält mehr Ergebnisse. Darum hat Anna die besseren Chancen.
