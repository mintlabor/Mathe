Ideen vergleichen

Welcher Vorschlag ist gerecht?

Ordnet eure Vorschläge den Karten zu. Entscheidet bei jeder Karte: gerecht oder nicht gerecht? Begründet mit dem Wort „Zufall“.

gerecht: Zufall entscheidet nicht gerecht: kein Zufall
🎩 Alle Namen in einen Hut, einer wird blind gezogen.Zufall: jeder hat die gleiche Chance
🏃 Wer am schnellsten um den Schulhof rennt.kein Zufall: die Sportlichen sind im Vorteil
📝 Wer die beste Mathenote hat.kein Zufall: steht schon vorher fest
🎲 Jeder würfelt, die höchste Zahl gewinnt (bei Gleichstand nochmal).Zufall
👩‍🏫 Die Lehrkraft bestimmt.kein Zufall: jemand entscheidet
🪙 Immer zwei werfen eine Münze, der Gewinner kommt weiter.Zufall

Beim Zufall kann niemand das Ergebnis vorhersagen oder beeinflussen. Darum ist er gerecht.

Zuerst die Vorschläge der Klasse den Karten zuordnen. Bei jeder Karte fragen: Warum gerecht, warum nicht? Fehlende Schülervorschläge ergänzen.

Unser Würfelexperiment

  1. Würfelt abwechselnd, insgesamt 30-mal.
  2. Macht nach jedem Wurf einen Strich in der Tabelle.
  3. Zählt am Ende die Striche für jede Augenzahl.

Überlegt danach:

  • Welche Zahl kam bei euch am häufigsten?

Sicherung

Das Zufallsexperiment

Schreibe den Merkkasten ins Heft. Löse dann das Lückenbeispiel.

Merke

  • Ein Zufallsexperiment hat mehrere mögliche Ergebnisse. Man weiß vorher nicht, welches eintritt. Man kann es beliebig oft wiederholen.
  • Alle möglichen Ergebnisse schreibt man in eine geschweifte Klammer { }.
Würfel: { 1, 2, 3, 4, 5, 6 }
Musterbeispiel: Glücksrad mit Rot, Blau und Grün
mehrere Ergebnisse? ✓ · vorher unbekannt? ✓ · wiederholbar? ✓
→ Zufallsexperiment
Ergebnisse: { Rot, Blau, Grün }
Jetzt du: Münzwurf: mögliche Ergebnisse { ______ , ______ }
Lösung Lückenbeispiel: { Kopf, Zahl }. Per 🎲 kontrollieren.
Übung

Jetzt rechnest du!

Rechne im Heft – erst die Mix-Aufgabe, dann so weit du kommst.

  1. Rechne um: 1/4 = ? %
  2. Schreibe alle möglichen Ergebnisse beim Münzwurf auf.
  3. Sicher, möglich oder unmöglich? Beim Würfeln fällt eine 7.
  4. „Wer am schnellsten rennt, bekommt die Karte.“ Ist das ein Zufallsexperiment?
  5. Erfinde ein Zufallsexperiment mit genau 3 möglichen Ergebnissen.
