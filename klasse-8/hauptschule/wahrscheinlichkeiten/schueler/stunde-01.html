Üben: Zufall oder nicht?

Stunde 1 · Zufallsexperimente und mögliche Ergebnisse

✏️ Aufgaben

📘 Merke

Ein Zufallsexperiment hat mehrere mögliche Ergebnisse. Man weiß vorher nicht, welches eintritt. Man kann es beliebig oft wiederholen. Alle möglichen Ergebnisse schreibt man in eine geschweifte Klammer { }.

Würfel: { 1, 2, 3, 4, 5, 6 }
Beispiel: Glücksrad mit Rot, Blau und Grün
mehrere Ergebnisse? ✓ · vorher unbekannt? ✓ · wiederholbar? ✓
→ Zufallsexperiment
Ergebnisse: { Rot, Blau, Grün }

Rechne jede Aufgabe zuerst im Heft. Trage dann dein Ergebnis ein und prüfe es.
